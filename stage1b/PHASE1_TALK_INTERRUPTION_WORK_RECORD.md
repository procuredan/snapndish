# Phase 1 release candidate: Talk It false interruption repair

## Pre-change boundary

- **Source and rollback:** The owner-approved Retail Shopping V4 baseline is source `d16ab8ffa8947c00e5839d13e9f9c5ec2003c228`, staging Worker `61f1eee7-87ee-49e0-b183-71ac7d7e7b6f`. Roll back only `snapndish-stage1b-staging` to that Worker if this repair fails. No D1/R2 migration or production change is required.
- **Existing authority:** The Worker creates a Realtime WebRTC session with semantic VAD and default automatic interruption/response. The browser accepts transcription and assistant turns through revision-fenced `/voice/events`; only the server owns the durable conversation and meal state.
- **Observed cause in code:** Automatic interruption can cancel a spoken reply at VAD start before a transcript exists. The browser treats an empty completed transcription as a fatal sync error and ends Talk It. This can also leave an empty input item or cancelled response ahead of later turns. The owner's cough/throat-clear reproduction is product evidence; the exact provider event trace was not recorded. A sanitized remote D1 status query was unavailable because the current Cloudflare credential returned 7403.
- **Narrow extension:** Keep semantic VAD, model, voice, transcription, prompts and tools. Disable only provider automatic interruption and reply creation. The browser requests a reply after the transcript is nonempty and its user turn is accepted; it cancels an in-progress reply for a genuine transcribed interruption. Empty/failed transcription is discarded without closing Talk It. No audio or incidental noise is stored.
- **Regression surface:** Genuine one-word and sentence barge-in latency, provider response event ordering, interrupted assistant turn persistence, tool-result ordering, multi-turn health, false sound recovery and the unchanged text/photo/meal package paths.
- **Proof plan:** Run all local tests, real Chrome fixture tests for event ordering, CI for the exact source, then isolated staging. A real Chrome microphone test must cover silence, cough, throat clear, kitchen noise, “wait,” a sentence, empty transcript recovery and subsequent turns before calling this fixed. Owner target-device observations remain necessary if the test machine cannot supply real microphone input. Preserve the current baseline until these gates pass.
